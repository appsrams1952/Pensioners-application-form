# Day to Day Routines (Mobile App)

A simple React Native (Expo) mobile app to track your day-to-day routines.

## Features

- Preloaded daily routine checklist
- Add your own routine items
- Tap a routine to mark it complete/incomplete
- Quick progress summary for the day
- Clear completed routines

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start Expo:

   ```bash
   npm run start
   ```

3. Open in Expo Go (Android/iOS) or emulator.

## Scripts

- `npm run start` - Start Expo server
- `npm run android` - Open Android target
- `npm run ios` - Open iOS target
- `npm run web` - Open web target
- `npm run typecheck` - Run TypeScript checks
